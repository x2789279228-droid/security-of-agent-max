## 一、背景与问题诊断

**现状**：React 19 + TypeScript + Tailwind 4 + Vite，22 页面/路由，约 3.7 万行 TS/CSS。UI 采用「机要室 / 案卷 / 刊物」编辑设计语言。

| # | 问题 | 证据 |
|---|------|------|
| 1 | 零信息量装饰标签 | 登录页 `ENTRY·CHAPTER 00`、`CLEARANCE REQUIRED`、`RESTRICTED`、`NODE·守望/VAULT` |
| 2 | 每页风格税 | PageFrame 强制 `值班台·Chapter I` + 148px 罗马数字幽灵水印 + ¶ 边注 20 处；170 处拉字距英文微标签；印章/封条/纸纹 |
| 3 | 中英混排与错误 | `SECURITY EVENTS·事件案卷`；`OSCILOSCOPE` 拼写错误 |
| 4 | 导航缺失 | v7 摘除 TopNav，跳页仅靠 CornerDock 浮钮 + Ctrl K |
| 5 | 动效过载 | index.css 32 个 @keyframes；每页多个"活"焦点并存；stagger 编舞 |
| 6 | 字重滥用 | font-black(900) 用于页标题/KPI/巨字 |

死资产：`ui/Card`、`ui/Seal`、`brand/BrandMark` 等组件零引用；CSS 死块约 20 处（~120 行）；吉祥物图片未被界面引用。

**根因**：把「刊物高级感」的手段（装饰）当成专业感来源。专业 SOC 的可信度来自：精确、密度、纪律。

## 三、设计规范（全站纪律）

### 3.1 色彩与层次
| 项 | 亮色 | 暗色 |
|---|---|---|
| surface | `#f5f7fa` | `#0f1216` |
| card | `#ffffff` | `#161b21` |
| inset | `#eef1f5` | `#10151b` |
| line | `#dde3ea` | `#2a323c` |
| ink 三档 | `#1c2838 / #5c6b7a / #8a97a4` | `#e9edf2 / #9daab6 / #6e7a88` |
| 强调·信号青 | `#0e7490`（hover `#155e75`） | `#4fb3cf`（hover `#6ec6de`） |

- 层次 = 三层底色差 + 1px 线；不堆阴影描边
- 语义四色：绿=健康、琥珀=降级、红=威胁、青=信息/交互；红只给威胁
- 几何：卡 6px、控件 4px、模态 8px、徽章全圆

### 3.2 字体（MiSans）
- sans 栈：`"MiSans","MiSans VF",system-ui,"PingFang SC","Microsoft YaHei UI","Noto Sans SC",sans-serif`
- mono 保留 IBM Plex Mono
- 引入：npm `misans`（woff2 unicode-range 子集 400/500/600）；不可用则 TTF→woff2 自托管 `public/fonts/`
- index.html 网络字体精简为仅 IBM Plex Mono；删 IBM Plex Sans / Noto Sans SC / Noto Serif SC
- 舞台页衬线本地兜底：`"Songti SC","SimSun",serif`
- **字重 400/500/600，600 封顶，全站禁用 900**

### 3.3 密度（Grafana 系）
- 表格行高 36、表头 12px 不加粗 sticky、数字右对齐 tabular-nums、时间/IP 等宽
- 卡内 12-16、卡间 16、区块间 24；page-shell（max-width 1680）保留
- KPI 带：标签 12 / 数字 28 / 字重 600 / 单位小一号灰一档

### 3.4 Panel 范式
工作页每区块 = 有边框面板：`13px 标题行（标题+右侧操作）+ 数据区`。替代自由排版与装饰框。

### 3.5 动效（工作页 6 种，缓动 `cubic-bezier(0.2,0,0,1)`，入场=透明度+4px）
fade-in 150ms / row-arrive 150ms·一次 / tick-flash 300ms·一次 / shimmer 1.5s 循环 / breathe 2s 循环（LIVE，每屏唯一常驻）/ spin 0.8s 循环。
**功能/舞台白名单 keyframes 保留**（仅限对应组件）：gauge-settle、duty-tape、watch-flame、edge-draw、edge-march、segment-flow、surge-sweep、pulseDot(star)。其余删除；live-arc 在工作页被 breathe 取代；stagger 编舞删除；Tally 数字滚动保留。

### 3.6 图片与文案
- 工作页零图片；空态用自绘 SVG 线条小图（雷达/放大镜/文件夹，1.5px stroke 单色 currentColor）
- 登录页背景 = 纯 CSS 材质（暗色极淡网格+径向渐变）
- 文案中文为主（领域缩写 JWT/Redis/KPI/LIVE/SIGMA 除外）；隐喻词替换（案卷→事件详情、卷宗尚未归档→暂无数据、入列→注册）
