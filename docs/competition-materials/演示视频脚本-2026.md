# 演示视频脚本（5-8 分钟 · 1080p · 普通话）

> 录制前置：`bash demo/run-demo.sh`（自动：起栈→登录→灌种子→注入攻击流量）。
> 录屏 2560×1600 缩放导出 1920×1080；浏览器建议全屏暗色。全程语速平稳，每幕先说"做什么"再说"看什么"。
> 兜底：断网可用 rehearsal 演示补给（前端按钮灌演示数据），脚本不变。

---

## 0:00-0:40 开场 · 定位与痛点（40s）

**画面**：Monitor 大屏实时事件带在滚动（攻击流量已注入）。

**口播**：
> "这是守望——一套治理优先的多智能体安全运营平台。安全运营中心的现实是：值班分析师每班面对数百条告警，九成是低价值重复；而让大模型直接自动研判，又带来幻觉与失控处置的新风险。守望的答案是：让 LLM 真正参与规划、研判和问答，但每一步都受程序化否决闸约束——拒绝要给理由，不确定就明确弃权。"

## 0:40-1:30 架构与核心数字（50s）

**画面**：切技术文档"图 3-1 五层架构"（或 README 架构段），再切 Benchmark 页数字卡。

**口播**：
> "平台五层：多源接入、Kafka/Flink 流处理、规则+异常+关联检测、四层智能体、React 交互层。几个对账数字：3283 项后端测试、1675 条 Sigma 规则、222 个 REST 端点，生成侧忠实度 0.9875——这些数字全部可以用仓库里的命令复现。"

## 1:30-3:00 【重头一】AI 对话交互（90s）

**画面**：Copilot 页。
1. 从 Monitor 事件行点"追问 AI"深链进入（带事件上下文）；
2. 输入问题，观察 ThinkingRail 三阶段步进 + 流式回答 + 引用 chips；
3. 中途点一次"停止"；点"重试"继续；
4. 粘贴一张截图（视觉未配置时展示诚实置灰与 vision_note 警告条）。

**口播**：
> "任意告警一键追问。注意三点：思考轨实时显示检索和生成阶段；回答里的结论都带引用编号，点开能溯源到知识块；视觉模型没配置时，系统如实告诉你这张图没有参与分析——不装有能力。停止和重试随时可用，重试不会丢掉附件。"

## 3:00-4:15 【重头二】思维链可视化审计（75s）

**画面**：SecurityAudit 页选一条 deep 档事件：
- 四层管线 DAG（Decomposer→ToolBuilder→Executor→Reviewer）逐步点亮；
- 展开证据链：断言↔事件 ID 逐字对应；
- 指出规划溯源 metrics（plan_source=llm / plan_selected）。

**口播**：
> "深度审核的事件可以看到完整的思维链：这一条的计划是 LLM 自己定的——它从七项取证能力里挑选了攻击链和实体关联，选择理由就在步骤里；综合分析和复核两个环节由代码强制保留，模型只能裁剪取证面、不能拆安全底线。每条断言绑定事件 ID 和逐字证据，这就是七层防幻觉的落地。"

## 4:15-5:15 【重头三】MCP 协议与治理（60s）

**画面**：终端 + 前端 Capabilities/治理面板交替。
1. `curl -X POST .../api/mcp` 发 initialize → 返回协议信息；
2. tools/list → 6 个治理工具带风险注解；
3. tools/call 调 alert_only（allow，返回执行结果）；
4. 再用低权限角色调 block_ip → isError 结果 + structuredContent.guard 决策明细。

**口播**：
> "平台提供标准 MCP 端点，JSON-RPC 2.0。关键设计：协议层只做翻译、不放松治理——权限或策略拒绝时返回 isError 工具结果，四层检查的完整明细透出给客户端，拒绝不黑箱。高危动作进审批队列，默认 dry_run。"

## 5:15-6:15 检测与响应闭环（60s）

**画面**：按 demo/README 六幕节奏快剪：
1. Sigma 告警命中 → 案例/工单自动生成（Operations）；
2. Response 页手动 block_ip 得 403 + 审批挂起 → 审批通过 → dry_run 留痕；
3. 复盘报告一闪。

**口播**：
> "从检测到响应的完整闭环：Sigma 规则命中自动开案建单；响应动作经过守卫，未授权直接拒绝，授权后也要人工审批，执行全程留痕可回滚。复盘沉淀回知识库，形成学习闭环。"

## 6:15-7:00 诚实与可信（45s）

**画面**：Benchmark 页评测表 + 终端跑 `pytest -q` 尾行绿 + GitHub Actions 全绿截图。

**口播**：
> "我们不回避限制：RAG 评测语料是 60 条回归基线、响应执行默认演练模式、多模态目前只有图像。但每个数字都可复现——检测回放 FP 是零、生成侧忠实度 0.9875 连失败样本都公开列出。3283 项测试和 13 道 CI 门禁保证说到的都做到。"
