# 公开数据集回放评测 — CSIC-2010

- 数据集: CSIC-2010(https://gitlab.fing.edu.uy/gsi/web-application-attacks-datasets (csic_2010))
- 规则库: 总 150 条(影子 125)
- 样本: 攻击 5000(签名可测子集 310) / 良性 5000
- 吞吐: ~31 eps(155 规则/事件, 单事件私有 SQLite)

## 核心指标

| 指标 | 数值 | 口径说明 |
|---|---|---|
| 原始召回(全攻击类) | 0.0132 | 引擎按真实接入口径(CSIC 异常类 ~80% 为纯行为异常) |
| **签名子集召回(原始 URL)** | **0.3452** | 双重编码载荷原样匹配 |
| **签名子集召回(解码规范化)** | **0.3452** | url 深解码后 —— 规范化解码器接入后的可达召回 |
| 良性误报 FP | **0** / 5000 (FPR=0.0) | enforced=非影子规则 |
| 规范化口径良性误报 | 0 / 0 | 仅对良性签名子集重跑 |
| 仅影子命中的攻击样本(全类) | 19 | 影子晋升候选池 |

> 签名子集原始与规范化召回的差值 = **双重编码规范化缺口**,
> 是已知的工程改进点(真实 IDS 均在匹配前做 URL 解码;平台接入
> 面的解码器属 ingest 规范化范畴, 记入 roadmap 而非规则缺陷)。

## 结论边界

- CSIC-2010 是 2010 年单一电商应用的合成注入流量, 规模/分布不代表生产;
- 签名子集由本工具的启发式正则界定(保守, 含经典 SQLi/XSS/遍历签名),
  其余为行为异常样本 —— 对签名引擎报告全类低召回是口径使然,
  行为面由平台 `anomaly_detector`/Flink 行为基线负责(见 B3 消融)。
